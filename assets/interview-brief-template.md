# Interview Brief 模板

```markdown
## Interview Brief

- 目标岗位 / 公司 / 轮次：（业务面 / 技术面行为部分 / HR 面 / 终面）
- 经历事实账本：已建（导入自 loop-resume-writer 或上次会话）/ 待建
- 在用简历版本：（供交叉核对；口径真相基准是账本、非简历——简历若与账本冲突则守账本。无则标「无简历在场」）
- 卖点一句话（草稿）：（「为什么是我」——过不了 Gate 就先收敛这句）
- 已知薄弱点：gap / 转行 / 短任期 / 项目角色边界模糊 …
- 距面试时间：（<24h → 建议考前速查模式）
- 目标公司面经（如有，用户自备）：（用于核对题型侧重，本 skill 不提供题库）
```
